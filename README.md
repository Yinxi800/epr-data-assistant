# EPR申报数据助手

React + TypeScript 中文本地报告解析工具。默认上传后直接展示解析结果并导出；国家、期间、产品与分类从报告读取。**只做解析、复核与通用申报准备，不连接店铺、不上传报告、不提交正式申报、不计算回收费。**

## Mac、Windows 与浏览器

Chrome / Edge 共用本地扩展；Mac、Windows 分别提供本地网页版启动包，Firefox、Safari 通过网页版使用。安装方法、运行前提与验证边界见 [系统与浏览器使用说明](docs/PLATFORM_SUPPORT.md)。开发者运行 `npm run package:platforms` 生成三个分发目录，`npm run test:compat` 验证打包网页版。

## 快速运行

需要 Node.js 22.12+（推荐 22 LTS）、npm。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认 http://127.0.0.1:4173 。本机也可运行 `./scripts/start-local.sh`。

```sh
npm test          # 计算、解析和导出测试
npm run build    # TypeScript 检查及生产构建
npm run test:e2e # 真实 Chromium 浏览器测试
npm run extension # 先 build，再生成无需服务器的浏览器扩展
```

浏览器测试首次运行可能需要 `npx playwright install chromium`。具体测试证据见 `docs/VALIDATION.md`。

## 浏览器扩展

`extension-dist/` 内含完整本地应用，不是远程跳转入口，无需保持本地服务器运行。点击扩展图标会在新标签页打开工具。

1. 运行 `npm run build && npm run extension`。
2. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目的 `extension-dist` 文件夹。
4. 点击扩展图标进入。扩展不申请店铺、网页内容、文件系统或网络主机权限。

应用安装至日常浏览器需用户在扩展管理页完成；不改动原有浏览器配置。更新后重新构建并在扩展管理页点“重新加载”。

## 默认直接解析（v0.2.4）

上传 → 自动展示产品／分类／材料 → 导出解析结果。默认不进入异常处理或人工确认流程，不要求先选择国家、期间、字段映射或复核结果。

- 国家、期间、产品、数量和重量从报告读取；不能确定的值保留为“未提供”，不补零、不推断。
- 产品搜索和选择位于表格上方，可搜索名称、ASIN、SKU；国家、EPR 类别、细分类、包装层级和来源文件筛选位于对应表头，可组合使用。细分类、包装层级独立成列；日期常显于表格上方，支持月/季/年、自定义起止及单边日期。按产品视图保留下方合计，按分类视图不重复显示合计。
- 筛选结果合计覆盖全部匹配记录，不受翻页影响。不同国家、期间、类别、原报告细分类、包装层级、渠道、文件及账户分别统计；材料拆分不重复计算数量，缺失重量不补零。
- 搜索和筛选只影响当前查看与合计；“下载全部数据”包含全部成功解析的文件及原始来源，按钮附近显示全量范围。
- 已解析页面采用全宽紧凑表格：桌面正文13px、表头/辅助文字12px；文件列表收在顶部可展开栏，保留添加、清除和失败重试入口。
- 包装细分类直接使用报告材料（纸、塑料等）；电子电器和电池使用原报告类型，已有中文参考时并列展示原文。未知类型不推断。Excel分别保留展示细分类和原报告子分类。
- 日期默认不限；启用日期后，期间不明的原始行不纳入当前筛选并显示数量，恢复全部期间可查看。跨期按原行完整值纳入并就地提示，不按天分摊。
- 当前筛选标签可逐项清除；表尾区分匹配原始行数与本页分组数，合计覆盖全部匹配记录。
- 读取失败的文件可单独重试或重新选择，不影响其他成功文件。
- 全部处理留在本地会话。解析结果不是正式申报文件，不自动扣退货或分摊运输包装。

此前三步复核功能保留在 `?review=1`，旧版高级工作台保留在 `?advanced=1`；均不出现在默认操作路径中。

## 高级工作台模拟演示

`public/samples/` 中的文件均为**模拟数据**，不是亚马逊真实报告。

1. 直接点击“载入模拟数据”，或上传支持格式的表格文件；国家从报告识别，无需先选择。
2. 字段映射页核对每个字段和小数格式，并勾选确认。
3. 选择“模拟客户A / 模拟店铺A”，期间 `2026-10-01` 至 `2026-10-31`。
4. 选择不扣退货，填写“模拟演示，人工确认不扣退货”；确认责任范围及特殊交易处理。
5. 检查异常，查看汇总。两个材料行分别演示 100 × 50 g = 5 kg，以及本行总重 5 kg 不再乘数量。
6. 复核后导出 Excel；存在缺失时仍可导出标明未完成的草稿与问题清单。

国家字段官方核验与本次适配范围见 [国家字段核验记录](docs/AMAZON_COUNTRY_FIELDS.md)。另提供 `模拟数据_亚马逊国家字段.csv` 验证德国商城下 DE / FR 目的国分别汇总；这是合成文件，不是真实卖家报告。

真实文件缺少客户、店铺或重量类型等关键字段时，应添加明确值或在工具中逐行修改并记录原因；不会从 ASIN、产品名或商城站点猜测。

## 已实现

- 国家默认从报告逐行识别并分别汇总，支持亚马逊 `SHIP_TO_COUNTRY_CODE` / `SHIP_TO_COUNTRY`；七国名称映射与可选筛选保留。包装、电子电器、电池选择。
- **所有国家与业务均未配置经核验的机构规则**。包装为完整通用演示，WEEE/电池为基础整理扩展入口，不能生成机构模板。
- CSV、TSV、TXT、XLSX、XLS、ODS 多文件、多工作表本地解析；工作表可选择是否纳入。哈希识别重复文件；重复记录只提示、不删除。
- 逐表字段映射、示例预览、明确确认、小数点/小数逗号格式选择。主动保存/载入映射（只保存映射，不保存报告内容），一键清除。
- 时间段支持按月份、自然季度、整年和自定义日期；自动计算起止日期，切换后撤销复核，跨期报告不自动分摊。这是整理筛选范围，不代表机构申报周期。
- 客户与店铺独立选择；多个目的国自动分组；国家代码与名称冲突/缺失时待处理，不以商城推断。可选单国筛选、业务和日期过滤均可追溯，跨越期间不按比例猜分。
- 单件/行总重分开；g/kg/t 换算；十进制精确计算；缺失不补零；重量类型不混用。
- 退货是否扣除需人工选择并写依据；责任范围及特殊流转确认；总重扣退货需人工核实本行总重量。
- 阻止计算、允许计算但需确认、提示三级检查；疑似重复、期间重叠、SKU冲突、估算与人工修改标记。
- 逐行原值/当前值、修改原因与时间、计算公式、来源文件/工作表/物理行号、筛选条件和汇总明细。
- Excel：数据汇总、标准化明细、异常及缺失清单、人工修改记录、字段映射及计算口径、原始数据。
- 问题 CSV 使用 UTF-8 BOM 与公式注入转义；Excel 数据为显式字符串，精确小数不丢失。

## 亚马逊标准列转换（v0.1.3）

自动识别账号、期间起止、商城、EPR 品类和销量列组成的报表结构，兼容大小写表头。字段映射页展示转换预览，可关闭自动转换或填写实际客户／店铺名称。

- `REPORT_PERIOD_START` / `END` 合成为期间，支持 `YYYY/M/D`、`YYYY-MM-DD`；无效日期仍阻断。
- `TOTAL_UNITS_SOLD` 保留报告数量，不另乘 `UNITS_PER_ASIN`。EEE 使用 `TOTAL_REPORTED_WEIGHT_KG`，不以四舍五入的单件净重重算。
- Primary / Secondary Packaging 转换为初级／运输包装；七种材料重量列按已填项拆分，作为本行总 kg，不再乘销量。显式零保留；空白列标为未知，不补零；全部材料缺失时阻断。
- 原报告 EEE 子分类独立保留、分别汇总，不推断为机构分类。未知 EPR 类别仍待处理。
- 未提供客户店铺名时，显示“报告账户／商城范围”作为分组键，不把商城推定为目的国或真实店铺名称。
- 必须核对转换口径、账户归属和空白材料处理，再确认字段与数字格式。估算状态未标明不代表实测。
- 按材料展示数量的同时，提供“按原始行核对数量”，只去除材料展开产生的重复，不自动删除原报告重复行。不同业务和包装层级数量不相加。材料之间数量修改冲突时阻断。
- 导出保留 7 张表（亚马逊额外增加“原始行数量核对”）：原始数据不因材料展开增加行数，标准化明细记录来源行、重量列、转换版本和修改记录。

一份用户提供的实际报告已在浏览器完成验证；并非所有站点、历史版本或机构规则均已核验。真实文件与测试导出仅保存在本机，不加入仓库。

## 计算边界

- 单件重量必须有明确数量口径；本行总重量只换单位，不重复乘数量。
- 选择扣退货后，已有总重不可自动按比例缩小。需在当前国家、业务、期间、客户店铺和退货口径下重新修改本行重量并记录原因。
- 取消订单、B2B/B2C、流转不作自动规则判断。人工核实后通过逐行修改或排除表达决定。
- 包装多材料行可能重复产品数量；分类数量不能跨材料相加视为唯一销量。
- 汇总只包含纳入行；待确认行保留候选计算值但不进入汇总。阻断行重量显示未知。
- 通用规则不进行机构特有取舍。重量和数量以精确小数字符串导出，Excel 中需要额外计算时应明确转换数值及精度。
- 估算标记缺失不代表实测，需结合数据来源复核。

## 隐私与限制

生产应用与扩展不包含分析服务、AI接口或报告上传端点。解析在独立 Worker 中完成。页面仅加载同源静态程序及用户主动载入的模拟文件；开发模式另有本机热更新连接。默认只保存在当前会话内存，刷新/关闭即丢失；下载的导出文件由用户管理，一键清除不会删除已下载文件。

每文件 ≤10 MB、≤20 工作表，当前会话 ≤20,000 行；每表 ≤100 列，单元格 ≤32,767 字符；Worker 解析超时 30 秒会终止。文本文件支持 UTF-8、GBK/GB18030、UTF-16 LE/BE，以及手动选择 Windows-1252；支持逗号、制表符、分号分隔。编码自动识别有歧义时须核对预览，可手动选择后重新导入。工作簿公式单元格拒绝导入，须先转为数值。含宏文件、加密文件、多层表头、合并表头不在支持范围；请先规范表头与数据。

当前不提供云端保存、登录系统、税费计算、官方模板导出或自动申报。已用一份用户提供的实际报告做本地导入验证，已跑通期间、EEE 与多材料列转换及 Excel 读回核对，**不声称兼容所有亚马逊报告版本**。实际报告和截图不纳入代码仓库。

格式支持表示能够读取文件，不等于已适配完整亚马逊字段与计算口径。公开截图、34 列结构诊断及适配边界见 [公开报告核验记录](docs/PUBLIC_REPORT_AUDIT.md)。

## 待真实脱敏样本核验

- 各站点报告版本、字段别名、列顺序、表头起始行、CSV 编码和分隔符。
- 原始日期格式、小数符号、Excel 数字显示与底层值差异。
- 销售/退货/取消数量含义，数量是否已净额，重量是单件还是汇总。
- 包装材料、层级、FBA/MFN责任范围与估算标记含义。
- 目的国证据、跨境流转、B2B/B2C、同产品多材料行及重复合法记录。
- 官方机构年度规则、分类、期间、取舍精度和模板；必须有可靠来源、核验日期、版本及人工确认后另行实现。

## 模块

`src/core/parser.ts` 和 Worker：导入与字段建议；`calculation.ts`：标准化/校验/计算；`rules.ts`：集中通用规则配置；`export.ts`：导出；`App.tsx`：操作流程；`extension/`：本地入口。

开发依赖按锁文件固定。SheetJS 从[官方安装来源](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)安装 0.20.3，浏览器运行不从 CDN 获取代码。

### 扩展打开提示找不到文件

推荐加载 `extension-dist`。运行 `npm run build && npm run extension` 后，`extension` 目录也会同步完整网页，避免误选源码目录时出现 `ERR_FILE_NOT_FOUND`。已加载的扩展可在 Chrome 扩展管理页点击“重新加载”后再打开。

### v0.2.5 重量与合计显示

重量明细使用紧邻的名称和数值，材料重量与产品／电池报告重量分别命名。数量列注明本类别／层级口径，不跨类别、层级累加。明细与合计均可展开零值；合计行可打开原始来源和缺失说明。导出的重量明细采用相同名称，原始值及计算口径保持不变。

### v0.2.9 材料分类（历史版本，已由 v0.3.0 替代）

新增“按材料”视图：纸、塑料、玻璃、铝、钢、木材和其他材料单独列行；按国家、报告日期、包装层级、类别、细分类、渠道、文件和账户分别汇总。支持材料筛选与原始来源查看。材料视图只列重量，不重复显示产品数量。Excel新增“按材料汇总”表。亚马逊空白材料列在材料视图保留为未知，0仍为0；未提供的更细纸种不自动猜分。

### v0.3.0 分类统一与数量核对

仅保留“按产品”和“按分类”。包装直接以纸、塑料等材料为细分类，按层级独立汇总；电子电器/电池保留原报告类型。重复的材料筛选及重量明细列已移除，重量明细可在来源面板查看。显示“重量小计/重量合计”，部分缺失显示范围，全部缺失仍为未知。

同批包装材料的报告数量在页面合并显示，Excel分类行不重复给出包装数量，统一通过“数量核对”表查看。导出表为：按产品分类、分类汇总、数量核对、原始报告、解析说明；取消重复的材料汇总表。不同源子分类仍保留区分，原字段不覆盖。

### v0.3.1 未提供项显示

明细与合计默认隐藏重量未提供的分组，可点击“显示未提供项”展开。零值及部分已知重量继续显示；仅改变显示，不修改数量、原报告及完整下载数据。

### v0.3.3 客户阅读体验

产品搜索与选择集中到表格上方，类别、层级等筛选仍在对应表头。文件名和账户信息移到来源列，同组减少重复；调整列宽与字号。来源面板增加本次取值摘要，收起或按 Escape 返回原按钮与阅读位置。通用自动识别说明集中显示，下载成功采用绿色勾选提示。

新增可选的“收起零值材料”：只收起重量完整、无异常的包装零值分组；部分缺失、异常和电子电器零值不受该开关影响。默认仍展开零值，完整导出保留全部数据。
