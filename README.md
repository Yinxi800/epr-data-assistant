# EPR 申报数据助手 · EPR Data Assistant

**[打开在线工具 · Open the web app](https://yinxi800.github.io/epr-data-assistant/)**

## 中文

在浏览器本地整理亚马逊 EPR 报告并导出 Excel。

- 支持多份 CSV 和 Excel，按产品、国家、类别、包装层级和日期筛选汇总。
- 可追溯原始记录，区分缺失重量与零值。Excel 下载包含完整数据。
- 文件不上传。支持 Chrome、Edge 本地扩展。工具仅用于数据整理，不提交申报或计算回收费。

## English

Review Amazon EPR reports locally in your browser and export to Excel.

- Import multiple CSV or Excel files. Filter and summarize by product, country, category, packaging level, and date.
- Trace figures to source records and distinguish missing weights from zero. Excel exports include the full dataset.
- Files stay on your device. A local extension is available for Chrome and Edge. The tool prepares data without filing declarations or calculating recycling fees.
