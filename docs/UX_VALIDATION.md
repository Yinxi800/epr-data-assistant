## 已发现并修复的交互问题

| 问题 | 修复与验证边界 |
|---|---|
| 保存后继续可能读到旧状态 | 保存提交同步更新待导出版本，导出读取最新状态；须通过下载文件内容断言验证 |
| 按已提交版本继续后丢失未保存输入 | 编辑面板开关与源行标识分离，保留输入并提供返回入口 |
| 小字号、短点击目标 | 表格和控件统一14px，来源与按钮最小44px |
| 侧栏与抽屉覆盖焦点 | 明确焦点描边、滚动预留，面板独立滚动 |
| 状态仅靠颜色 | 所有状态含文字，问题含严重性及修正建议 |
| 下载提示可能被理解为落盘成功 | 使用“已生成并发起下载，请检查浏览器下载记录” |
| 汇总页首屏被复核表单占据 | 数据表前置，文件清单及人工复核放在表格后、导出前 |
| 大汇总组渲染大量来源按钮 | 单元格仅显示前5条，全部来源在分页面板中查看 |
| 对话框键盘可进入背景 | 编辑面板打开时背景 inert，Tab/Shift+Tab 在对话框内循环 |
| 范围错误远离输入 | 在范围编辑区显示错误并将焦点移至错误信息 |

## 检查范围与边界

- 原始数据、客户名称、搜索词、国家和期间不写入公开 URL；会话数据留在内存，主动副本提供本地恢复。这是隐私与工作流决定，不把 URL 视为完整任务备份。
- 空白重量保持未知、显式 0 单独保留；数据问题未解决的原始行及其拆分材料不会进入可核对汇总。
- 表格采用25/50/100条分页；导出使用完整任务，不采用当前页或搜索结果。
- 深蓝和绿色状态均不表示国家机构认可或正式申报通过。
- 默认只支持浅色；未声明独立暗色主题或屏幕阅读器全量认证。
- 自动化测试和真实报告下载结果由主实现验证记录补充；本文件的颜色计算和代码检查不能替代真实操作测试。
