## 自动化

- `npm test`：32 项计算/解析/导出测试通过。
- `npm run test:e2e`：8 项真实 Chromium 测试通过；扩展导出增强断言单独复跑通过。
- `npm run build`：TypeScript 与生产构建通过。
- `npm run extension`：本地应用、解析与导出 Worker 打包完成。
- `npm audit`：升级测试依赖后 0 个已知漏洞。

运行环境：Node 22.19.0；本机独立 Chromium snapshot。`PLAYWRIGHT_CHROMIUM_EXECUTABLE` 可指定测试浏览器，未设置时用 Playwright 自带 Chromium。系统 Chrome 限制命令行侧载，因此扩展使用独立 Chromium 实测，不改动用户日常 Chrome 配置。

截图和测试下载在忽略的 `output/playwright/` 目录；测试源码和模拟文件入库。截图仅证明所示状态，不能替代真实样本验证。
